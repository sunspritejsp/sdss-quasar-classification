# SDSS Quasar Classifier

This is a collaborative Machine Learning project aiming to classify astronomical objects (quasars and stars) based on real photometric data extracted from the **Sloan Digital Sky Survey (SDSS)**.

---

## Scientific Context

Differentiating common stars from quasars (massive and distant active galactic nuclei) is a classic challenge in astronomy. Due to the expansion of the universe, light from quasars undergoes the redshift phenomenon, altering the brightness signature captured by astronomical filters. This project utilizes classification algorithms to automatically identify these patterns.

The variables used correspond to the five photometric filters of the telescope:
* `u` (Ultraviolet)
* `g` (Green)
* `r` (Red)
* `i` (Near-Infrared)
* `z` (Far-Infrared)
